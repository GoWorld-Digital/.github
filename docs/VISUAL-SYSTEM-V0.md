# GENESIS — Guia de visualização v0.1 (provisório)

Este guia **não aprova identidade visual**, logótipos, fontes, imagem de marca ou campanha. Não utiliza assets de terceiros.

- **Metáfora:** do escuro cósmico à primeira luz; de elementos soltos à rede de relações.
- **Paleta de exploração:** espaço profundo, navy, ciano de observação, dourado de primeira luz.
- **Formas:** órbitas, pontos conectados, halos, constelações e gradientes. Não copiar design de filmes, marcas ou produtos existentes.
- **Tipos de dados:** `SIMULATION`, `MANIFEST`, `OBSERVED`. Cada estado deve ser facilmente identificável também sem cor.
- **Movimento futuro:** estrelas lentas, órbitas e partículas em SVG/CSS ou WebGL. Respeitar `prefers-reduced-motion`, desempenho mobile e acessibilidade. Não usar animações que escondam estados ou sugiram operações reais.
- **Github README:** SVG estático original + Mermaid, sem JavaScript. A Galaxy 3D interativa deverá viver num site dedicado após testes.
- **Publicação:** toda alegação empresarial, produto, cliente, equipa operacional, resultados e captação deve ser revista antes de publicação.
